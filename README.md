# Comande
Point-of-Sale software for restaurants and hotels aimed at touch devices and tablets. It is possible to integrate with the hotel PMS software that expose an open API. Currently, there is a placeholder for the API connection.

# To Make it work
In order for you to use the software you have to change the placeholder API, the txt menu and, if needed, provide encryption for the signing box(depends on whether your use case needs to send this data through the public network)
